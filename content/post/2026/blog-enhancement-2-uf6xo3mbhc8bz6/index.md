## テーマの自作化「Liquid Glass」

一番大きな変化はこれです。これまで使っていた [hugo-theme-stack](https://github.com/CaiJimmy/hugo-theme-stack) をフォークして、
自作テーマ [hugo-theme-stack-liquid-glass](https://github.com/rin2yh/hugo-theme-stack-liquid-glass) を作りました。

### Liquid Glass UI
名前のとおり、すりガラス（Liquid Glass）風の見た目に寄せたUIにしました。
既存テーマをそのまま使うのも良いのですが、細かいところを自分好みに直そうとすると、
結局フォークして触るのが早いという結論に至りました。

### git submodule 化
最初はテーマのファイルをブログのリポジトリに直接置いていたのですが、
テーマとコンテンツが混ざって管理しづらかったので、別リポジトリに切り出してgit submoduleにしました。
オリジナルのstackもsubmoduleで管理する構成なので、それに倣った形です。

### バージョン管理
テーマ側にちゃんとバージョンを切って（v0.2.0 → v0.3.0 → v0.4.0）、
ブログ側はsubmoduleのバージョンを上げるだけで更新できるようにしました。
自作テーマとはいえ、リリースの粒度で管理すると変更履歴が追いやすくて気持ちが良いです。

### ブランドアイコン
ソーシャルリンク用にブランドアイコン（X など）を追加しました。

## CI・開発環境の整備

記事を書くだけでなく、書きやすい・壊れにくい環境も整えました。

### Hugo ビルドチェック
Pull Request時にHugoのビルドが通るかをCIで確認するようにしました。
submodule込みでビルドが壊れていないか、マージ前に気づけるので安心感があります。
併せてビルドキャッシュのパス周りも直しました。

### textlint 導入
日本語の文章校正に [textlint](https://textlint.github.io/) を導入しました。
`preset-ja-technical-writing` と `preset-ja-spacing` をベースに、
自分の書き味に合わないルールは `.textlintrc.json` で無効化しています。
`mise run lint` / `mise run lint:fix` で手元でも回せるようにしつつ、
CIでも `content/**/*.md` を検査するようにしました。
表記揺れやスペースの入れ忘れを機械的に潰せるので、地味に効きます。

## OGP・Twitter Card 画像

記事のタイトル入りOGP画像（Twitter Card）を自動生成する仕組みを入れました。
Goで背景画像に記事タイトルを描画するジェネレータを書いて、
シェアされたときに味気ない見た目にならないようにしています。

一度はブログ側に実装したのですが、「これはテーマの責務では？」と思い直し、
テーマ（stack-liquid-glass）側へ移設しました。
オリジナルのstackが画像解決を一箇所に集約している設計に倣い、
テーマのOGP画像フォールバックの流れに組み込む方針にしています。

ちなみにOGP対応は前回ログのあとに一度別アプローチで試してうまくいかず、
巻き戻した経緯もあります。試行錯誤の跡が残っていて、それはそれで趣があります（笑）

## シェアボタン改善

X（Twitter）のシェアボタンまわりを調整しました。
テーマの共有ボタンが使うアイコンを、リポジトリに既にあったXロゴを再利用して差し替えています。
PCサイドバーのシェアウィジェットと、スマホ右下のフローティングボタンの両方で、
ちゃんとXのアイコンが出るようになりました。地味ですが、スマホでの見た目が整って満足です。

## 試して、やめたもの
